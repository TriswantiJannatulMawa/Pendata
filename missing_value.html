Missing Value#

Missing value adalah kondisi ketika suatu data tidak memiliki nilai atau kosong pada suatu atribut dalam dataset. Missing value biasanya muncul karena beberapa faktor seperti kesalahan pencatatan, data yang tidak lengkap, atau kesalahan saat proses pengumpulan data.

Menangani Missing value#

Ada beberapa metode untuk menangani missing value

  1. Menghapus data (deletion) Yaitu dengan menghapus data yang memiliki nilai kosong dan cocok jika jumlah missing value kecil

  2. Mengisi dengan Mean, Metode ini digunakan jika data berupa numerik

  3. Mengisi dengan Median, Metode ini digunakan jika data memiliki outlier

  4. Mengisi dengan Modus, Digunkan untuk data yang katagorikal

  5. Interpolasi, Mengisi nilai yang hilang berdasarkan pola data

Informatika

dari data diatas terdapat data yang kosong atau belom diketahuin nilainya,yang harus kita lakukan yaitu

  1. Menghitung jarak gower

\[ d(i,j) = \frac{\sum_ {d_ij}}{p} \]

dimana:

  • d(i,j) = jarak opjek x dan y

  • p = jumlah atribut yang dibandingkan

atribut: Numerik

\[ d= \frac{|x_i - x_j|}{max - min} \]

Kategorikal

\[ d = 0(jika sama) \]
\[ d = 1 (jika berbeda) \]

  1. Menentukan nilai min max

\[\text{range} = \text{max} - \text{min} \]

umur:

\[ 24-19 = 5 \]

semester:

\[ 8-2 = 6 \]

  1. Menghitung jarak M6 dengan M1

umur:

\[ \frac{24-20}{5} = 0.8 \]

semester:

\[ \frac {8-4}{6} = 0.67 \]

jurusan: berbeda -> 1

total:

\[ \frac {(0.8+0.67+1)}{3} = 0.82 \]

  1. Menetukan tetangga terdekat

tetangga terdekat adalah jarak yang paling kecil,setelah dihitung seluruh jaraknya maka nilai yang disebut tetangga terdekat yaitu M2. karena tetangga terdekat adalah M2, maka nilai IPK M6 diambil dari M2 yaitu 3.80.

2. Menentukan 3 tetangga terdekat#

dari data diatas terdapat 4 data yang nilainya sama maka kita pilih 3 teratas yaitu data ke 1,2 dan 4.

  • d(1) = 0.5 (JML=0)

  • d(2) = 0.5 (JML=1)

  • d(4) = 0.5 (JML=1)

3. Hitung bobot#

\[ w = \frac{1}{d^2} \]
\[ w = \frac{1}{0.5^2} = 4 \]

4. Prediksi nilai JML#

\[ JML = \frac{(w \cdot JML_1) + (w \cdot JML_2) + (w \cdot JML_4) }{w + W + w} \]
\[ JML = \frac{(4 \cdot 0) + (4 \cdot 1) + (4 \cdot 1) }{4 + 4 + 4} = 0.67 \]

Prediksi akhir JML data ke 7 yaitu 0.67

Implementasi Code#

import pandas as pd
import numpy as np
from sklearn.impute import KNNImputer

# Data yang sudah ternormalisasi
data_norm = {
    'IPK': [0, 0.5, 1, 0, 0.5, 1, 0],
    'PO': [0, 0.5, 0, 0, 0.5, 1, 0.5],
    'JML': [0, 1, 0, 1, 0, 1, np.nan] 
}

df = pd.DataFrame(data_norm)

# Inisialisasi WKNN dengan k=3
imputer = KNNImputer(n_neighbors=3, weights='distance')

# Lakukan Imputasi
df_imputed = pd.DataFrame(imputer.fit_transform(df), columns=df.columns)

print("Hasil Imputasi JML baris ke-7:")
print(df_imputed.iloc[[6]])
